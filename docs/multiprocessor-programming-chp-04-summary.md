<h1 align="center">多处理器编程的艺术</h1>
<h2 align="center">第四章 共享存储器基础 总结</h2>

## 1. 主题与核心思想

本章研究并发共享存储计算的基本理论：从**最弱的寄存器**（SRSW 安全布尔寄存器）出发，逐步构造出**更强的寄存器**，最终证明各种寄存器在可计算性上是**等价**的——任何使用原子寄存器的算法，都能在只支持安全寄存器的硬件上实现。

本章侧重"是否存在、如何工作"，不考虑效率，使用简单但无界的构造（如时间戳）。

## 2. 寄存器空间

**寄存器接口**：`read()` / `write(v)`，封装一个值（布尔、整数或对象引用）。

**按读写线程数分类**：

- SRSW（单读单写）< MRSW（多读单写）< MRMW（多读多写）

**一致性层级**（由弱到强）：

| 类型 | 定义 |
|---|---|
| **安全** | 读写不重叠时返回最近写入值；**重叠时可返回取值范围内任意值** |
| **常规** | 安全 + 与写重叠时，只能返回"重叠写或最近不重叠写"写入的值（不能任意） |
| **原子** | 最强，读返回线性化次序中最近一次写入的值 |

**三条判定条件**（以写入次序的索引 i/j 描述）：

- **(4.1.1)** 读不返回未来的值。
- **(4.1.2)** 读不返回太旧的值（不跳过最近一次不重叠的写）。
- **(4.1.3)**（仅原子）若 R^i —> R^j 则 i ≤ j（读操作不倒退）。

满足 (4.1.1)+(4.1.2) = 常规；再加 (4.1.3) = 原子。

## 3. 寄存器构造

构造链条：SRSW安全布尔 → MRSW安全布尔 → MRSW常规布尔 → MRSW常规M-值 → SRSW原子 → MRSW原子 → MRMW原子。

**MRSW 安全寄存器**：用 SRSW 安全寄存器数组，写者遍历写全部格子，读者读自己那一格。

**MRSW 常规布尔寄存器**：布尔只有"新旧相同/不同"的区别，**只在值变化时才真正写入**（用 ThreadLocal 记住上次值），避免安全寄存器在"写同值"时让读读到任意值。

**MRSW 常规 M-值寄存器**：用 M 个常规布尔寄存器做**一元编码**。写 x：置 `r_bit[x] = true` 并清空所有更低位；读：从 0 向上扫描，返回第一个 true 的索引。

**SRSW 原子寄存器**：引入**时间戳**（StampedValue）。读者记住最近读过的最高时间戳值，读到旧值（低时间戳）就忽略，从而保证读不回退，满足 (4.1.3)。

**MRSW 原子寄存器**：n×n 数组 `a_table`。写者只写对角线 `a_table[i][i]`；读者读自己所在列取最大时间戳，再把自己读到的最大值**写进自己所在行**——即**间接帮助**：让较早的读者把信息传给较晚的读者，避免"后读的反而更旧"。

**MRMW 原子寄存器**：MRSW 数组，每个格子对应一个线程。写者先读全部格子，选一个比观察到都大的时间戳写入自己的格子（按 (时间戳, 线程ID) 字典序，同面包房锁）；读者返回最大时间戳元素。

## 4. 原子快照

**目标**：以原子方式读取**多个**寄存器数组的瞬时视图。`update(v)` 写自己的格子，`scan()` 返回数组快照。

先看**简单快照**（scan 无阻塞、update 无等待）：采用**双重收集**——连续两次 collect，若两次读到**所有时间戳都相同**，则为"干净"，第二次收集即为有效快照。**必须比较时间戳而非值**，否则值反复变化又回到原值时，会误判"没变"，得到错误快照。

为了把 scan 也做到**无等待**（WFSnapshot）：update 在写前先 scan 一次，把快照附进值中（StampedSnap：stamp + value + snap）。scan 用 moved[] 记录迁移者；**观察到某线程迁移两次**时，可直接借用它的快照——因为第二次迁移的 update 必然在本次 scan 区间内开始，其快照可在此区间线性化。

**正确性**：干净双重收集返回的值必是扫描期间某个状态存在的值（引理 4.3.1）；观察到两次迁移即可安全借用（引理 4.3.2）；借用的快照可通过归纳证明合法（最多 n-1 层嵌套，引理 4.3.3）；scan/update 至多 O(n²) 步（引理 4.3.4）→ **无等待**（定理 4.3.5）。

## 5. 核心收获

- 无等待性排除互斥，保证**独立演进**（不依赖调度器）。
- 两个算法工具：**时间戳**（区分新旧）与**帮助**（间接帮助 / 相互帮助——一个线程替被自己打断的线程完成工作，是无等待的关键范式）。
